# Ivan Torrente Portfolio

A public website presenting Ivan Torrente's work history, skills and contact details to recruiters and collaborators.

## Language

**Selected Work**:
A short description of work from Ivan's employment history, naming the employer and tech used, with no link or screenshot required.
_Avoid_: Project, portfolio item

**Project**:
A piece of work with a real case study and its own detail page.
_Avoid_: Selected Work, app

**Experience**:
A dated role in Ivan's work history. Experience entries are the evidence for the years claimed on the site.
_Avoid_: Job, position

**Earlier Experience**:
Experience from before Feb 2019, not on the current resume, that Ivan must add before Launch.
_Avoid_: Past work

**Hidden Section**:
A section whose collection is empty, so visitors see no section, nav link or listing page.
_Avoid_: Disabled, coming soon

**Launch**:
The first production deployment, which requires Experience supporting the "10+ years" claim. Preview deployments are not Launch.
_Avoid_: Go-live, release

**Studio**:
The login-protected editing dashboard where Ivan manages all content, including the profile photo.
_Avoid_: Admin, CMS page
