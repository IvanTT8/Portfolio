# Sanity holds all site content

All site content, including rarely changing resume data such as skills and Experience, lives in Sanity. The repo holds only layout and components. A CMS is more than a personal portfolio strictly needs, and repo files would have been cheaper, but Ivan wants to edit everything from a dashboard without committing code. Keeping only the growing collections in Sanity was rejected because a new job would then still require a code change, and content would have two homes.
